# Voca 词库数据包

ECDICT 词库的完整导出，共 **38,855 条**词条，覆盖 **8 本**考试词书。

---

## 数据来源与许可

数据来自 [ECDICT](https://github.com/skywind3000/ECDICT) 开源词典，
采用 **MIT License**（Copyright © 2025 Linwei），许可全文见 `LICENSE-ECDICT.txt`。
按 MIT 条款，本数据包保留原始版权声明，可自由使用、修改与再分发。

构建流程：

```
ECDICT 全量词条（约 340 万）
    │  按 tag 字段筛选：zk / gk / cet4 / cet6 / ky / toefl / ielts / gre
    │  清洗音标字符（西里尔字母 → 国际音标，如 ә → ə、є → ɛ）
    │  去重
    │  按词频排序
    ▼
8 本词书 → voca.db
```

| 中文名 | 标签 | 说明 | 词条数 |
| --- | --- | --- | --- |
| 中考核心 | `zk` | 初中阶段必备词汇 | 1,603 |
| 高考核心 | `gk` | 高中阶段必备词汇 | 3,677 |
| 四级核心 | `cet4` | 大学英语四级大纲词汇 | 3,849 |
| 六级核心 | `cet6` | 大学英语六级大纲词汇 | 5,407 |
| 考研核心 | `ky` | 硕士研究生入学考试词汇 | 4,801 |
| 托福核心 | `toefl` | TOEFL 高频词汇 | 6,974 |
| 雅思核心 | `ielts` | IELTS 高频词汇 | 5,040 |
| GRE 核心 | `gre` | GRE 高阶词汇 | 7,504 |

> 同一单词可能同时属于多本词书，因此各库词数之和（38,855）大于去重后的唯一单词数。

## 包含的文件

```
voca-words/
├── voca.db              词库本体（SQLite）
├── all-words.csv        全部 38,855 条，UTF-8 with BOM（Excel 可直接打开）
├── all-words.json       同上的 JSON 版本，便于程序读取
├── schema.sql           表结构说明
├── LICENSE-ECDICT.txt   ECDICT 的 MIT 许可全文
├── books/
│   ├── index.csv        各词库索引
│   ├── <book>.csv       分库完整数据：id, book, headword, phonetic, pos, meaning, rank
│   ├── <book>.tsv       分库简化对表：word + meaning 两列，制表符分隔
│   └── <book>.txt       分库纯单词表，每行一个，便于导入其他背单词软件
└── README.md
```

### 字段说明

| 字段 | 含义 |
| --- | --- |
| `id` | 词条唯一编号（同一单词在不同词库里是不同行，各自独立编号） |
| `book` | 所属词库标识，见上表 |
| `headword` | 单词 |
| `phonetic` | 音标 |
| `pos` | ECDICT 的词性频次统计（形如 `v:15/n:85`），非词性标签，保留原始值 |
| `meaning` | 中文释义，多个义项以换行 `\n` 分隔 |
| `rank` | 词频序，数值越小越常用；缺失则为一个极大值 |

## 已知不足

- **音标不是严格 IPA**：ECDICT 沿用其自身的通用标注体系，例如 `state` 标作 `/steit/`
而非 `/steɪt/`。对认读影响有限，但若需要精确国际音标，需替换数据源。
- **释义为中文简释**，不含例句、搭配与词根词缀，也不含英英释义。
- `pos`** 字段语义容易误解**：它是该词各词性的出现频次统计，不是词性标签本身；
真正的词性标注写在 `meaning` 每行开头（如 `n.`、`vt.`、`a.`）。
- **各库难度标签由 ECDICT 标注**，同一词可能同时挂在多个标签下（例如既在 cet4 又在 toefl），
这是原始数据的特性，未做互斥处理。

## 不包含什么

本数据包**不包含**任何第三方 App 的词库数据。特别说明：

- List背单词 的 `VocabularyDataBase.sqlite3` / `WNAListDataBase.sqlite3` /
`WBAListDataBase.sqlite3` **不在其中** —— 那些是原开发者的版权资产，未导出、未复制。
- 仅 `WNAListDataBase` 的数据结构源自 [WordNet](https://wordnet.princeton.edu/) 的公开词典，
如其英英数据有需要，可直接使用 WordNet 官方发布版本。

## 想要完整版 ECDICT？

`ecdict-sqlite-28.zip` 等完整数据包。
