# Voca v1.1.0 — WordReference 原页面内嵌与序列/导出整改报告

日期：2026-11-18。按用户在 v1.0.9 实机截图上的四点意见开发（截图同时证明 1.0.9 的宿主抓取桥已在实机跑通：accumulate 词条成功抓取并显示）。

## 1. WordReference 改为显示原始网页

用户口径：解析成文本条目「效果还是不太行，要在 VOCA 中显示原始网页」。

实现（宿主叠加视图）：
- 宿主 `voca_host.c` 新增第二个 WebView2 控制器，父窗口为主窗口（与主 WebView 共用同一 Environment，Cookie/验证状态共享）。
- 前端在弹窗内备好 `#modalDictIframeWrap` 框（既有 embed 框，高度 clamp(240px, 46vh, 660px)），经消息通道发 `{voca:"dict-show", url, x, y, w, h, dpr}`（框的 CSS px 视口坐标）；宿主按 dpr 换算物理像素 put_Bounds + put_IsVisible(TRUE) + Navigate——顶层导航，站点 XFO 不适用，Anubis 在原页面内自行完成。
- 宿主在叠加视图首次 NavigationCompleted 后回 `{voca:"dict-shown", ok}`；前端据此置成功横幅。窗口 resize 与页面滚动（capture）时发 `{voca:"dict-rect"}` 同步位置；弹窗关闭（按钮/Esc/保存）、切换词典来源、其它渲染路径接管时发 `{voca:"dict-hide"}`（hide 挂在 clearFrame 与两个关闭点上）。
- 回退链：叠加失败（ack ok:false 或 9 秒无 ack）→ 1.0.9 的宿主抓取+解析文本显示 → 弹窗内按钮在词典窗口打开源页面。普通浏览器无宿主时自动跳过叠加步。

无头验证（假宿主桥）：dict-show 携真实坐标（636×414 CSS px）发出、fetch 次数 0、横幅「✓ 已在弹窗内打开…原页面」、关弹窗发出 dict-hide；ack 拒绝时自动落回抓取解析且条目干净。宿主 exe 已交叉编译（267,264 B，二进制含 dict-show/dict-shown/dict-rect/dict-hide 协议串与 v1.1.0 标题）；叠加视图的实机效果（DPI 缩放下与弹窗框的对齐）待用户在 Windows 上确认。

## 2. 序列整改

- 设置页计划序列删除 hard_first（不会的单词排前面）与 easy_first（易掌握的单词排前面）——两者按学习记录排序，只适用于 List 内，不应出现在选词书/定计划处。计划序列现为 随机/初始/字母升序。
- 学习页 List 序列删除 easy_first（保留 hard_first）。
- 存档归一：planConfig.sortMode 为 hard_first/easy_first → initial（摘要实测显示「初始序列」）；intraSort=easy_first 经既有白名单校验落回 random（实测 sortSelect 显示 random）。
- sortPoolByMode 与 getSortedActiveWords 中对应的死分支已删除。

## 3. 导出整本词书

- 数据页导出卡新增「导出『整本词书完整单词表（双语对照版）』」按钮：按定格计划的 List 顺序拼接全书词条，走既有双语表生成器与打印预览；文件名 `四级核心_整本词书.pdf` / `.html`。实测四级核心导出表格 4,450 行（4,449 词 + 表头）。
