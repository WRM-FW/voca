# Voca v1.1.2 — 导出整改与 Agent 提示词重写报告

日期：2026-11-19。按用户对 1.1.1 的实机反馈开发。

## 1. 导出整改

用户反馈三点：直接导出的 PDF 很糊；PDF 页脚还写着 1.0.6 版本；「调用系统打印 / 另存为 PDF」删掉；用户主要在电脑上用，推荐导出 HTML。

- **糊的原因**：直接 PDF 是手写 PDF 生成器，每页先在 1240×1754（约 150 dpi）的 canvas 上绘制再转 JPEG 0.90 嵌入。改为 2 倍渲染（2480×3508，约 300 dpi，ctx.scale 缩放、图像对象宽高同步，JPEG 0.92）。实测生成的计划表 PDF 内含 /Width 2480，文件约 1.0 MB / 4 页。代价是整本导出体积明显变大，故 HTML 仍是推荐路径。
- **版本字样**：页脚的「Voca v1.0.6 …」是 1.0.6 时代写死、历次升级都没人碰的字符串（这就是用户看到的 1.0.6 来源）；计划表标题与单词表副标题里的「Voca v1.1.1 …」一并清除。所有导出文档现在只写 VOCA（标题/副标题/页脚「VOCA · 第 X / Y 页」）。无头实测：整本 HTML 导出全文无 vX.Y.Z 字样、含「生成自 VOCA」、4,449 行齐全。
- **删系统打印**：弹窗按钮与 click 处理（window.print 流程）全部删除；弹窗标题改「导出预览」，数据页导出卡标题改「导出 PDF / HTML」并写明推荐 HTML；两个「PDF/打印版」按钮标签去掉「打印版」。
- **HTML 推荐化**：弹窗内 HTML 按钮改为第一位、主按钮样式、标注（推荐）；PDF 按钮降为次按钮；弹窗 meta 文案同步。

## 2. Agent 提示词重写

旧提示词是五段式要求文档（读/转/写/安全/验收），用户反馈「还是不行」：要描述关键信息（如文件路径）、不要太多约束。新版 632 字，只包含：要写的文件（软件目录 app 文件夹里的 voca_auto_import.js，与 index.html 同目录；找不到就问、不要猜）、可直接照抄的追加格式示例（__VOCA_AUTO_IMPORTS__.push 一条批次）、三条底线（只有 word 必填、缺字段留空不编造、id 每次换新）、收尾报告导入数量与文件路径。无头断言：含路径与格式、全文无旧版「具体要求/数据安全」段落、长度 < 1000。
