# Voca v1.0.8 — CET-4 Complete Word List Report

Date: 2026-11-18. Windows-only (Android remains paused). Content release:
adds the 4,449-word CET-4 list used by the user's "CET-4" study space as a
built-in book. `schemaVersion` stays at 4; v1.0.0 ~ v1.0.7 archives load
unchanged.

## What was added

- **New book `cet4full` — 四级完整词表 (CET-4 · 4,449 words)**, placed right
  after 四级核心 in the book selector. Rows follow the source list's own
  order (sequence 1..4449); with the plan order mode set to 原序版本 the
  in-app lists match the source list page by page (verified: List 1 starts
  plastic, steal, preferable, summarize, chart). The default 乱序 mode
  behaves exactly as it does for every other book.
- **Overlap handling.** The list contains 4,441 unique headwords; 4,424
  already existed in the lexicon and keep their richer ECDICT definitions
  and examples. Three list spellings are truncations/notations in the
  source itself (inser, accommodatio, systematic(al)) and are mapped to
  the existing entries insert / accommodation / systematic. Eight rows are
  duplicates inside the source list (grant, forbid, angle, china, present,
  kingdom, communism, Polish) and map to the same entry with distinct
  sequence numbers, sharing one headword-keyed learning record.
- **14 genuinely new words** were appended to the lexicon, each with a
  bilingual example written for this release: o'clock, a.m., aero, etc.,
  Jew, esp., eleventh, AI, meter, Brazil, dramatization, quickly,
  Portugal, Brazilian. Their glosses come from the source list (lightly
  re-punctuated to house style; the garbled a.m. gloss was cleaned to
  上午，午前）.
- **Totals.** Book rows 38,855 → **43,304**; unique words 14,942 →
  **14,956**; examples coverage remains 100% of unique words (14,724
  generated/curated pairs + 233 rich entries, one overlapping key).
  Hardcoded totals in the UI were updated, and the storage diagnostic now
  reads `VOCA_PACK.totalRows` dynamically so future books cannot stale it.

## Verification (headless Chromium)
- Book selector lists cet4full; switching to it shows 4,449 words across
  15 lists (297 per list at the default plan size); diagnostics read
  43,304 entries.
- 原序 mode reproduces the source order exactly (first five words match
  the source list's #1–#5).
- Cross-book search finds the new word "quickly" attributed to 四级完整词表
  and jumps to it with the highlight flash.
- Zero page errors throughout; all pre-existing books unchanged.

## Addendum (same day): interaction overhaul folded into 1.0.8

At the maintainer's direction the 1.0.8 scope grew beyond the word list
before the release was cut. All items below were verified headless
(zero page errors; the v1.0.7 regression suite still passes):

- **Auto-scroll training mode removed.** Training is spelling-only; the
  panel, speed control, rAF loop and hover/touch pause wiring are deleted.
- **Plan rebuilt around the Ebbinghaus curve.** The user sets only the
  List count; days are derived as the canonical Ebbinghaus table:
  exactly one new List per day (List i learned on Day i), reviews at
  fixed intervals +1/+2/+4/+7/+15, total N + 15 days. Measured: 15
  Lists → 30 days; a 60-List schedule was verified cell-by-cell against
  the user-supplied canonical reference table (75 days, 450/450 cells
  identical). (An earlier pacing draft — ≤2 new/day under a 5-List
  daily cap, 33 days for 15 Lists — was replaced at the user's
  direction.)
- **Top bar scoped.** Book/List selectors render only where they act
  (learn: both; plan: book only; train/notebook/data/settings: neither),
  as do the language/sort/view controls.
- **Data page slimmed.** The storage-path/migration guide card is
  deleted; body text is 723 characters (was several thousand).
- **Dictionary modal.** Shows the local lexicon definition + example
  instantly at the top; the raw query-URL line is gone; the Settings
  duplicate of the source selector is removed (the modal switcher is the
  single persisted control).
- **Row click fixed.** One behaviour (click/tap +1 with pronunciation,
  right-click/long-press −1); the four-mode selector and its alternative
  code paths are deleted. First-click hint retained.
- **Australian accent removed** (`en-AU` archives migrate to `en-US`).
- **core233 book removed** (see above): selector entry, embedded dataset
  (~190 KB), notebook pool and custom-book demo fallback all go with it;
  `currentBook: "core233"` archives migrate to `cet4`.
- **Visual refinement layer**: softer card borders/shadows, 10px control
  radii, pill segmented controls, hairline row dividers, 18px modals.
- **Agent import**: the import card gains a copyable agent prompt + guide;
  an agent-produced CSV was test-imported successfully (2/2 words landed
  in the custom book).
- **Agent import upgraded to direct write-in** (user direction): the agent
  appends batches to `app/voca_auto_import.js`; the app auto-merges new
  batch ids into the custom book at startup (word-level dedupe, applied
  ids persisted). Headless test: 2 batches / 4 entries with one
  cross-batch duplicate -> exactly 3 words; second launch added nothing;
  missing file is a silent no-op.
