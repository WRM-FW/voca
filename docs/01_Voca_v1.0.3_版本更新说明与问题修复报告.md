# Voca v1.0.3 版本更新说明与问题修复报告

## 一、Windows 任务栏图标模糊的根因定位与修复

### 1.1 实际根因确认
经对 v1.0.2 的 `voca.ico`、`Voca.exe` `.rsrc` 资源表及 `index.html` 进行二进制解析，确认导致 Windows 任务栏图标模糊的三个具体原因：
1. **Chromium `--app` 模式任务栏图标降采样（主因）**：`Voca.exe` 启动 `msedge.exe --app=".../app/index.html"` 后，任务栏活动窗口图标由 `index.html` 的 `<link rel="icon">` 决定。v1.0.2 仅声明了一个无 `sizes` 属性的 64×64 `data:image/png` 图标，Chromium 的 `FaviconHandler` 默认将其按网页标签页标准缩放到 `16×16` 位图后再交给 Windows 任务栏（`WM_SETICON`），被系统放大到 32×32 / 40×40 / 48×48 时产生严重模糊。
2. **PE `.rsrc` 与 `.ico` 缺少标准 32-bit BGRA DIB 帧及多 DPI 阶梯**：v1.0.2 的 `Voca.exe` `.rsrc` 仅嵌入了 64×64 和 32×32 两个尺寸，且小尺寸直接存放了 PNG 字节流而非 Win32 Shell 标准要求的未压缩 32-bit BGRA `BITMAPINFOHEADER` DIB + 1-bit AND 掩码帧，缺少 256×256、128×128、48×48、40×40（125% 缩放任务栏）、24×24（150% 小图标）及 16×16。
3. **源图标内边距偏大与缺少 PerMonitorV2 DPI 清单**：原裁剪框外围留白偏宽，在小尺寸下主体 `V` 占比偏小，且 `.exe` 未嵌入 `RT_MANIFEST` 高 DPI 感知声明。

### 1.2 修复方案
1. **重构 8 级分辨率 Win32 标准 `voca.ico` 与 `Voca.exe` `.rsrc`**：
   - 以 `V+书本负形图标` 主体为中心进行 `1080×1080` 内渐变区精准居中裁剪，通过单步高阶 Lanczos 下采样与 8 倍超采样圆角矩形掩码生成 `256, 128, 64, 48, 40, 32, 24, 16` 共 8 个尺寸；
   - `256×256` 采用 PNG 帧，`128 / 64 / 48 / 40 / 32 / 24 / 16` 全部编码为标准 32-bit BGRA `BITMAPINFOHEADER` DIB + 底部对齐 1-bit AND 掩码帧，同时嵌入 `windows/voca.ico`、`windows/app/voca.ico` 与 `Voca.exe` 的 `.rsrc` 节；
   - 在 `Voca.exe` `.rsrc` 中新增 `RT_MANIFEST (Type 24, ID 1)` 声明 `PerMonitorV2` 高 DPI 感知，并向浏览器内核传递 `--high-dpi-support=1`。
2. **补全 HTML 多尺寸 `<link rel="icon">` 声明**：
   - 在 `index.html` 中显式声明 `sizes="256x256"`、`192x192`、`128x128`、`64x64`、`48x48`、`32x32`、`16x16` 的高清 PNG 图标与 `voca.ico` 引用，并将侧边栏 `.brand-logo` 升级为 `256×256` 高清源。

## 二、删除“掌握度”并仅保留“不会程度”

- **界面与交互清理**：移除单词行、沉浸卡片、词典弹窗、拼词模式中的全部「掌握度 (`0/5`)」徽章、翠绿右边框与加减按钮；移除排序下拉框中的「掌握程度从低到高」；移除 PDF 与 CSV 导出中的掌握度列（替换为不会程度列）。
- **不会程度 (`unfam`, 0~5) 完整交互**：
  - 单词行默认支持**左键点击加深不会程度 (+1) 并发音**、**右键点击降低不会程度 (-1)**，并在设置中提供 4 种不会程度点击分区模式；
  - 沉浸卡片与词典详情弹窗均提供 `不会程度 -1`、`不会程度 +1` 与 `重置不会度` 按钮。
- **数据结构平滑迁移**：加载旧版存档时自动删除每个单词记录中的 `mastery` 属性，完整保留 `unfam`、`starred`、`mastered`、`customCn` 与 `note`。

---

## 三、“查看词典详细与编辑”重构与在线词典选择设置

- **删除旧区块**：已从 `#dictModal` 弹窗中彻底删除「英英释义与同义词拓展」与「双语语境例句与助记」两个区块。
- **双在线词典集成**：
  - 支持 **欧路词典 (`https://dict.eudic.net/dicts/en/@word@`)** 与 **WordReference 英汉词典 (`https://www.wordreference.com/enzh/@word@`)**，通过 `encodeURIComponent` 处理空格、连字符等特殊字符；
  - 在「偏好设置与帮助」中提供 `#settingOnlineDict` 持久化设置项，并与弹窗内的词典切换器双向同步；
  - 严格区分并诚实展示 **加载中**、**查询成功**、**词条不存在 (404)** 与 **网络不可用/请求失败** 四种状态，离线或失败时自动隐藏 `<iframe>`，绝不将空白框或错误页伪装成正常词典结果。

---

## 四、删除“英英模式”

- 已移除顶部工具栏中的「英英模式」按钮、快捷键 `4`、首次模式提示中的 `en_en` 分支以及列表/卡片中的英英渲染分支；
- 若用户旧版存档停留在 `en_en` 模式，升级至 v1.0.3 时自动切换为 `bilingual`（双语模式）。
